# MyCharPanel Epic

A World of Warcraft addon for viewing and managing character information, inventory, bank contents, and character history.

## Features

- Character information and statistics
- Character archiving
- Inventory and bank tracking
- Gold tracking
- Playtime statistics
- Customizable character overview
